Network Gateway

Connecting physical measurements to a networked application.

A sensor acquisition system on the ZedBoard, combining a 12-bit ADC and a MAX31865 temperature interface with a multithreaded TCP server on embedded Linux.

Zynq-7000C / POSIXTCP/IPSPI
Project details +

My contribution

Developed embedded Linux acquisition and server software in C, using POSIX threads, timerfd-based periodic sampling and a mutex-protected ring buffer to exchange measurements between acquisition and networking threads.

System integration

04 / MEASUREMENT SYSTEMSNOV 2024 – FEB 2025

Acceleration
Measurement System

Built a microcontroller-based measurement unit to estimate vertical displacement from acceleration, combining analog conditioning, data logging and MATLAB analysis.

ATmega32Analog design / PCBUART / microSDMATLAB
Project details +

Signal chain

Designed an analog signal-conditioning circuit with a Butterworth low-pass filter and an op-amp amplifier, and assembled a custom PCB.

Acquisition & analysis

Programmed the ATmega32 for 100 Hz sampling with UART and microSD logging. Used MATLAB for calibration, numerical integration and velocity-drift correction to estimate floor-to-floor displacement. Across six elevator trips, the reported mean displacement was 3.685 m with a standard deviation of approximately 0.153 m.

CORDIC sine/cosine generator

Implemented rotational-mode CORDIC in Xilinx Model Composer as a seven-stage fixed-point hardware model. Used shift-add arithmetic without multipliers and compared simulated outputs with MATLAB reference functions.

Fast Fourier Transform
